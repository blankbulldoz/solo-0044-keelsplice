    $summary

原始 JSON（同一配方）

逐根格的内容会按同一份配方显示在这里。可以直接粘贴既有 { "table": "表名", "key": [主键值] } 配方，再点「导入 JSON 为逐根格」继续逐根编辑；或点下方「按原始 JSON 保存」原样提交。

整数为有符号 64 位 JSON 数字；文本为空字符串时保留空串；字节用 {"blob":"AAD/"}；实数用 {"real":"0x1.a000000000000p+1"}。
