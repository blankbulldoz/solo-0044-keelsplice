# 只凭替代材料仍不能确认的原始结论

替代包是**结构同构、内容全合成**的重放载体。它能证明工作台在各类关系形态
下的判定机制，但下列关于原始库的结论，复核组无法从本包得出，必须回到工位
内的受控证据（原库、封存记录或其授权摘要）核对。

## 1. 原始根与行的真实身份

- 内部库复合主键的真实文本（地区/代码的实际拼写与大小写组合）、真实 BLOB
  字节、真实 `mark`、盒序号、帧号均未出现在本包中。替代根
  `North/Quartz`、`South/Granite` 与原始根没有可推导关系。
- 因此“某条真实业务记录是否曾被选为根”“真实根的实存拼写是什么”“真实
  BLOB 是否等于某个外部样本”等身份级结论，无法确认。
- 替代库中每个 NOCASE 父键各安排了两个不同拼写的子行，这只证明**机制上**
  大小写折叠如何工作，不能证明原始库里真实存在过哪些拼写变体、各自多少行。

## 2. 原始数据的基数、分布与时间线

- 替代库是固定的小样本（父表 2 行、盒 3 个、assay 4 行、帧 4 行）。原始库
  的真实行数、扇出宽度、循环个数、NULL 比例、是否存在更长的循环链或更复杂
  的共享行，均无法从本包推断。
- 重放中“修改 T-10 后再封存”演示的是同模式对比机制；原始库中真实发生过
  哪些值变更、变更顺序、由谁在何时封存，属于工作台状态库的历史事实，替代
  材料不含这些时间线。
- 捕获 ID（`replay_manifest.json` 中的不透明字符串）是本次重放随机生成的，
  与内部任何真实捕获 ID 无对应关系，不能用于交叉检索。

## 3. 替代材料刻意破坏的值级结论

- 所有数值（`length_um`、序号、帧号）、文本标签与 BLOB 均被替换，且刻意
  选取与内部值不同的数。任何关于“真实测量值是多少”“真实标签为何”的
  结论，在本包中既不能证实也不能证伪。
- 替代库与内部库 DDL 同构只覆盖 `microscope.sql` 已有的四张表与两条索引；
  内部若还有其他表、视图、触发器或扩展关系，本包不提供任何信息，也无法
  判断工作台对它们的选样结论。

## 4. 可以确认与不能确认的边界

| 结论类型 | 替代材料能否支持 |
| --- | --- |
| NOCASE 复合键的根定位、实存键规范化、追踪必须用实存键 | 能（机制级，correct_a/b + wrong_1） |
| 复合子键含 NULL 时无必需父行、NULL 外键不扇出 | 能（机制级，correct_b/c） |
| 自引用循环按行身份去重、不无限展开、尾盒与循环成员入选路径不同 | 能（机制级，correct_a/b + wrong_4） |
| 行预算/无效键/缺失根/未知边/模式漂移的拒绝语义 | 能（机制级，wrong_2..wrong_5） |
| 认证子库的结构、外键、生成列、字节摘要一致性 | 能（针对替代封存本身） |
| 原始根、原始行值、真实 BLOB、真实标记与编号 | **不能** |
| 原始库的行数、分布、扇出规模、循环数量与 NULL 比例 | **不能** |
| 真实变更历史、封存时间线、捕获与配方的对应身份 | **不能** |
| 演练库结构之外的任何内部表或关系的结论 | **不能** |

## 5. 复核建议

若需要把机制级结论升级为对原始库的事实级结论，应在工位内针对同一配方
重新封存并导出**证书摘要与计数**（不含行值的最小披露），与本包的机制行为
逐项比对；需要值级核对时，再按既有授权流程在受控环境中打开原始捕获，
而不是向外部转发原始键值。
